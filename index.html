2. Fundamental Data Types

In Python, each piece of data has a type. The most common data types are numbers, text strings, lists, dictionaries, and booleans.

Example 3: Variable Definition
book_name = "The Pragmatic Programmer"
integer_number = 100
decimal_number = 1.967857
authorized = True
selected = False

To define variables we only specify the variable name followed by the = sign and then the value we want to assign.

Numbers

Integers and Decimals

int: Numbers without decimals (5, -10, 0)
float: Numbers with decimals (3.14, -2.5, 0.0)

Example 4: Working with Numbers
integer_number = 42
decimal_number = 3.14159

sum = integer_number + decimal_number
print(f"Sum: {sum}")

# Mathematical operations
print(10 * 5)      # Multiplication: 50
print(20 / 4)      # Division: 5.0
print(2 ** 3)      # Power: 8
print(17 % 5)      # Modulo (remainder): 2

Text Strings (Strings)

Working with Text

Strings are created with single ('') or double ("") quotes. You can use both interchangeably.

Example 5: Text Strings
name = "Python"
message = 'It is an amazing language'

# Concatenation (joining strings)
result = name + " " + message
print(result)

# Useful methods
print(name.lower())        # python
print(name.upper())        # PYTHON
print(len(name))           # 6 (length)

Lists

Ordered Collections

Lists store multiple values in an ordered container. They are mutable and can contain different data types.

Example 6: Lists
fruits = ["apple", "banana", "orange"]
numbers = [1, 2, 3, 4, 5]

# Access elements
print(fruits[0])             # apple
print(fruits[-1])            # orange (last element)

# Add elements
fruits.append("strawberry")

# Iterate through a list
for fruit in fruits:
    print(f"Fruit: {fruit}")

Dictionaries

Key-Value Pairs

Dictionaries store data as key-value pairs. They are perfect for organizing related information.

Example 7: Dictionaries
person = {
    "name": "Juan",
    "age": 25,
    "city": "Madrid"
}

# Access values
print(person["name"])     # Juan

# Add or modify
person["age"] = 26
person["country"] = "Spain"

# Iterate
for key, value in person.items():
    print(f"{key}: {value}")

3. Control Flow: Decisions and Loops

Control flow allows you to make decisions in your code and repeat actions. They are the foundation of any program.

Conditionals: IF, ELIF, ELSE

Making Decisions

if: If the condition is true, execute the code
elif: Another condition if the first is false
else: If no condition is true

Example 8: Conditionals
age = 20

if age < 13:
    print("You are a child")
elif age < 18:
    print("You are a teenager")
else:
    print("You are an adult")

Loops: FOR and WHILE

Repeat Code

for: Iterates over elements of a collection
while: Repeats while a condition is true

Example 9: FOR Loop
numbers = [1, 2, 3, 4, 5]

for number in numbers:
    print(f"Number: {number}")

# Use range()
for i in range(5):
    print(f"Iteration {i}")

List Comprehension

Example 10: List Comprehension
# Create list with squared numbers
squares = [x**2 for x in range(10)]

# With condition
even = [x for x in range(10) if x % 2 == 0]

# Transform list
words = ["python", "is", "amazing"]
uppercase = [p.upper() for p in words]

4. Functions and Methods

Functions are reusable blocks of code that perform specific tasks. They are essential for writing organized and efficient code.

Define and Use Functions

What is a Function?

A function is a set of instructions that perform a task. It is defined once and can be used multiple times.

Example 11: Basic Function
def greet():
    print("Hello, welcome!")

# Call the function
greet()

# Function with parameters
def greet_person(name):
    print(f"Hello, {name}!")

greet_person("Juan")

# Function with return
def add(a, b):
    return a + b

total = add(5, 3)

Lambda Functions

Example 12: Lambda Functions
# Lambda: Anonymous one-line function
square = lambda x: x ** 2
print(square(5))  # 25

# Use with map()
numbers = [1, 2, 3, 4, 5]
squares = list(map(lambda x: x**2, numbers))

5. Object-Oriented Programming (OOP)

OOP is a programming approach that organizes code into objects. Objects contain data (attributes) and behavior (methods).

Classes and Objects

Key Concepts

Class: Template for creating objects
Object: Instance of a class
Attributes: Variables of the object
Methods: Functions of the object

Example 13: Define a Class
class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def greet(self):
        print(f"Hello, I am {self.name}")

# Create objects
juan = Person("Juan", 25)
juan.greet()

Inheritance

Share Behavior

Inheritance allows a class to inherit attributes and methods from another class.

Example 14: Inheritance
class Animal:
    def __init__(self, name):
        self.name = name

class Dog(Animal):
    def make_sound(self):
        print(f"{self.name} barks: Woof!")

dog = Dog("Rex")
dog.make_sound()

🐍 PYTHON EXERCISES

1. Count Frequencies (EASY) ▼

Problem: Given a list of numbers, count how many times each one appears.

numbers = [1, 2, 2, 3, 3, 3, 4, 4, 4, 4]

Expected: {1: 1, 2: 2, 3: 3, 4: 4}

from collections import Counter
def count_frequencies(numbers):
    return dict(Counter(numbers))
2. Reverse Dictionary (EASY) ▼

Problem: Reverse a dictionary (keys ↔ values).

original = {"a": 1, "b": 2, "c": 3}

Expected: {1: "a", 2: "b", 3: "c"}

def reverse_dictionary(dictionary):
    return {v: k for k, v in dictionary.items()}
3. Remove Duplicates Keeping Order (EASY) ▼

Problem: Remove duplicates but keep the original order.

numbers = [1, 2, 2, 3, 1, 4, 3, 5]

Expected: [1, 2, 3, 4, 5] (order of first appearance)

def remove_duplicates(lst):
    return list(dict.fromkeys(lst))
4. Find Second Largest (EASY) ▼

Problem: Find the second largest number in a list.

numbers = [10, 20, 30, 40, 50]

Expected: 40

def second_largest(numbers):
    sorted_list = sorted(set(numbers), reverse=True)
    return sorted_list[1]
5. Group Even and Odd (MEDIUM) ▼

Problem: Group numbers into two lists: even and odd.

numbers = [1, 2, 3, 4, 5, 6, 7, 8]

Expected: {"even": [2, 4, 6, 8], "odd": [1, 3, 5, 7]}

def group_even_odd(numbers):
    return {
        "even": [n for n in numbers if n % 2 == 0],
        "odd": [n for n in numbers if n % 2 != 0]
    }
6. Find Intersection (MEDIUM) ▼

Problem: Find common elements between two lists.

list1 = [1, 2, 3, 4, 5]
list2 = [3, 4, 5, 6, 7]

Expected: [3, 4, 5]

def intersection(list1, list2):
    set2 = set(list2)
    return [x for x in list1 if x in set2]
7. Sort List of Dictionaries (MEDIUM) ▼

Problem: Sort a list of people by age (descending).

people = [
    {"name": "Juan", "age": 30},
    {"name": "Maria", "age": 25},
    {"name": "Pedro", "age": 35}
]

Expected: [Pedro (35), Juan (30), Maria (25)]

def sort_by_age(people):
    return sorted(people, key=lambda p: p["age"], reverse=True)
8. Find Duplicates (MEDIUM) ▼

Problem: Find numbers that appear more than once.

numbers = [1, 2, 2, 3, 3, 3, 4]

Expected: [2, 3]

from collections import Counter
def find_duplicates(numbers):
    return [n for n, count in Counter(numbers).items() if count > 1]

🐍 Key Python Topics

Lists, Sets, Dictionaries

List Operations

Append: Add to end | Pop: Remove by index | Remove: Remove by value

Slicing: list[1:4] | Reverse: list[::-1]

lst = [1, 2, 3, 4, 5]
lst.append(6)
lst.pop(0)  # Remove first element
sublist = lst[1:4]  # Elements from index 1 to 3

Sets

Main use: Remove duplicates, O(1) searches

Operations: Union | Intersection | Difference

my_set = {1, 2, 3, 4, 5}
union = set1 | set2
intersection = set1 & set2
difference = set1 - set2

Dictionaries

Safe access: dict.get("key", "default")

Iterate: for key, value in dictionary.items()

person = {"name": "Juan", "age": 30}
name = person.get("name", "N/A")
# Dict comprehension
squares = {x: x**2 for x in range(5)}

List Comprehension (VERY IMPORTANT)

Basic Syntax

[expression for element in iterable if condition]

# Simple
squares = [x**2 for x in range(10)]

# With condition
even = [x for x in range(10) if x % 2 == 0]

# With transformation
words = ["python", "is", "amazing"]
uppercase = [p.upper() for p in words]

Essential Functions

Search/Order: len() | min() | max() | sorted() | sum()

Transform: map() | filter() | zip()

Enumeration: enumerate() | range()

🗄️ Key SQL Topics

Basic SELECT

SELECT with Columns

-- All columns
SELECT * FROM users;

-- Specific columns
SELECT name, email FROM users;

-- With alias
SELECT name AS "User Name" FROM users;

WHERE - Filter

Simple Conditions

SELECT * FROM users WHERE age > 30;
SELECT * FROM users WHERE city = 'Madrid';
SELECT * FROM users WHERE age BETWEEN 25 AND 35;
SELECT * FROM users WHERE city IN ('Madrid', 'Barcelona');

Aggregate Functions

COUNT, SUM, AVG, MIN, MAX

SELECT COUNT(*) AS total FROM users;
SELECT SUM(salary) FROM employees;
SELECT AVG(age) FROM users;
SELECT MAX(salary) FROM employees;

GROUP BY

Group and Count

SELECT city, COUNT(*) AS total
FROM users
GROUP BY city;

-- With HAVING
SELECT city, COUNT(*) AS total
FROM users
GROUP BY city
HAVING COUNT(*) > 1;

JOINs - Combine Tables

INNER JOIN

Combines only records that match in both tables.

SELECT u.name, p.title
FROM users u
INNER JOIN posts p ON u.id = p.user_id;

LEFT JOIN

All records from the left table, even if there's no match.

SELECT u.name, COUNT(p.id) AS posts
FROM users u
LEFT JOIN posts p ON u.id = p.user_id
GROUP BY u.id;

Difference: WHERE vs HAVING

WHERE vs HAVING

WHERE: Filters BEFORE grouping (applies to rows)
HAVING: Filters AFTER grouping (applies to groups)

-- WHERE: filter before
SELECT city, COUNT(*) FROM users
WHERE age > 25
GROUP BY city;

-- HAVING: filter after
SELECT city, COUNT(*) FROM users
GROUP BY city
HAVING COUNT(*) > 1;

🎯 Interview Tips

Python

1. List Comprehension is Your Friend

Use it whenever you can. It's Pythonic, readable and efficient.

2. Know the Built-in Functions

len(), sum(), min(), max(), sorted(), enumerate(), zip(), map(), filter()

3. Dictionaries vs Sets

Sets: To remove duplicates, O(1) search
Dictionaries: For key-value mappings, O(1)

4. Write Clean Code

✓ Clear variable names
✓ Don't do everything in one line
✓ Explain your logic verbally

SQL

1. Read the Question Twice

Make sure you understand what is being asked before writing.

2. Identify the Main Table

Which table is the starting point? Do you need a JOIN?

3. Understand JOINs

INNER: Only matches
LEFT: All from left
RIGHT: All from right

4. Practice on SQLZoo.net

Excellent interactive platform for SQL. 30 min/day = great improvement.

General

Interview Checklist

  • Write pseudocode first if you're unsure
  • Don't try to be "clever", clean code is better
  • Ask if you don't understand the question
  • Test your code with examples
  • Ask about edge cases (empty list, duplicate values, etc)
  • Explain your solution out loud as you write
